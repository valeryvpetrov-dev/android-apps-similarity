# Dataset cube status

Дата: 2026-06-12.

Это единственный рабочий экран состояния датасетов.

Правило чтения:

- `m0_run_items`: сколько строк брать для M0-запуска.
- `ready_pool_items`: сколько готовых строк есть в пуле источников.
- `missing_ready_items_to_m1`: сколько готовых положительных пар или случаев не хватает до минимального M1.
- `negative_items_ready`, `split_status`, `explanation_tags_status`: отдельные блокеры M1.

Для M0-запусков использовать `m0/m0_canonical_pairs.csv`.
`m0/m0_seed_pairs.csv` остается пулом источников, а не планом работы.
