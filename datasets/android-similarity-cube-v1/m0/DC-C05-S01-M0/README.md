# DC-C05-S01-M0

Дата: 2026-06-11.
Статус: материализованный пул `piggybacking` для M0 и источник для `DC-C05-S01-M1`.

Канонический M0 использует ровно 2 строки из `../m0_canonical_pairs.csv`.

## Что внутри

- `manifest.csv` — 20 внешних `piggybacking`-пар как материализованный пул.
- `materialization_status.csv` — состояние скачивания, декомпиляции и извлечения признаков по каждой паре.
- Полных готовых пар сейчас: 20.
- APK для этих пар: 40; все скачаны во внешний кэш, декомпилированы и прошли извлечение признаков.

## Разрешенное использование

Этот набор можно использовать для технического M0-прогона, подготовки M1 и ручного разбора C05.
Для канонического M0-запуска брать `../m0_canonical_pairs.csv`, а не весь `manifest.csv`.

## Запрещенное использование

Нельзя считать этот набор claim-ready benchmark и нельзя делать широкие выводы о качестве метода.

## Следующий шаг

Использовать этот пул как вход для `DC-C05-S01-M1`: отрицательные пары, split и теги объяснений формируются отдельным M1-скриптом.
