# M0 controlled materialization

Дата: 2026-06-11.

Файл фиксирует локально сгенерированные маленькие APK-пары для заполнения M0.

Сами APK лежат в `m0/generated-apks/` и не коммитятся.
В git хранится только CSV с путями, SHA-256, правилом генерации и результатом проверки.

## Сводка

- строк: 16
- `C02`: 2
- `C03`: 2
- `C04`: 2
- `C06`: 2
- `C07`: 2
- `C08`: 2
- `C09`: 2
- `F01`: 2

## Проверка

Для каждой строки выполнены:

1. сборка APK через `apktool build`;
2. подпись тестовым ключом через `jarsigner`;
3. повторное декодирование через `apktool decode`;
4. расчёт SHA-256.

Эти пары пригодны только для M0: технические проверки, smoke-прогоны и проверка каналов признаков.
