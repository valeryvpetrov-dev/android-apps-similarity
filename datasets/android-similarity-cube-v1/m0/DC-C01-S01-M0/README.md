# DC-C01-S01-M0

Дата: 2026-06-10.
Статус: материализованный пул `repack` для M0 и кандидат на M1.

Канонический M0 использует ровно 2 строки из `../m0_canonical_pairs.csv`.

## Что внутри

- `manifest.csv` — 7 внешних `repack`-пар из `AZ-PILOT-001`, перенесенных в координату куба как пул.
- Все 14 APK находятся во внешнем кэше, не в git.
- Все 14 APK успешно декомпилированы через `apktool`.
- По всем 7 парам извлечены простые статические признаки.

## Разрешенное использование

Этот набор можно использовать для:

1. проверки, что контур попарного сравнения запускается на внешних APK;
2. демонстрации связи между координатой куба и реальными SHA-256;
3. первичного ручного разбора `repack`-пар перед расширением до `M1`.

Для канонического M0-запуска брать `../m0_canonical_pairs.csv`, а не весь `manifest.csv`.

## Запрещенное использование

Этот набор нельзя использовать для:

1. вывода о качестве метода;
2. расчета `F1`, `precision`, `recall`;
3. утверждения, что `DC-C01-S01-M1` уже готов.

Причина: 7 положительных пар достаточно для M0-проверки, но мало для рабочего набора с разбиением и отрицательными парами.
