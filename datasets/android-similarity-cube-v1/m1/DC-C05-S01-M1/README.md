# DC-C05-S01-M1 ready

Дата: 2026-06-11.

Это M1 diagnostic set для `C05 code_injection` и сценария `S01 pair_similarity`.
Он собран из материализованных Piggybacking APK.

## Состав

- положительных piggybacking-пар: 20
- отрицательных пар: 20
- split: dev, holdout
- строк тегов объяснений: 92

## Статус

`ready M1 diagnostic`, не `claim-ready benchmark`.

Минимальный M1 закрыт структурно: есть 20 чистых положительных C05-пар, отрицательные пары, split и теги объяснений.
Ручная проверка тегов объяснений остается отдельным шагом перед сильными выводами.

## Файлы

- `manifest.csv`: положительные и отрицательные пары M1 diagnostic set.
- `pair_change_tags.csv`: теги для проверки объяснений.

## Разрешенное использование

Можно использовать для M1-диагностики, ручного разбора, проверки отрицательных пар и проверки формата тегов объяснений.

## Запрещенное использование

Нельзя считать этот набор claim-ready benchmark и нельзя переносить выводы за пределы малой C05-диагностики.
